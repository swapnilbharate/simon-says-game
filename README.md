# 🎮 Simon Says Game

A fun and interactive memory-based game built using HTML, CSS, and JavaScript.

## 🚀 Features
- Color pattern memory game
- Increasing difficulty with levels
- Sound effects for each button
- Game over detection and restart functionality

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (DOM Manipulation & Event Handling)

## 🎯 How to Play
1. Press any key to start the game
2. Watch the pattern carefully
3. Click the buttons in the same sequence
4. Each level adds a new color to the pattern
5. Game ends if you press the wrong button
